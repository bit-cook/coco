# Co Web Desktop Snapshot

This directory contains CoCo-owned runtime assets for the native Co Web
service. `desktop/` is generated by `scripts/vendor-coweb-static.mjs` from a
reviewed, MIT-licensed Pi Web browser-client build. It is served as static
client data only: CoCo's native Node service owns every API, session, auth, and
SSE endpoint.

The only CoCo UI addition is `coweb-mobile.css`, which is constrained to
viewports at or below 699px so desktop layout remains unchanged.
