What we build on

今天的 CoCo 已有可靠底座

重新审查的结论很积极：CoCo 不是从零开始，也不是简单包装器。最有价值的本地安全、任务恢复和发布工程已经存在；现在要做的是让这些优势拥有更清晰的生产边界。

KEEP

可恢复的本地任务内核

事务状态、进程身份、取消、worktree、event、log 和 receipt 构成可持续扩展的核心。

GROW

可验证的发布体系

Closure、完整性、secret scan、离线包和安装生命周期已经齐备，下一步升级为原子发布。

OWN

源码级产品体验

选择性 fork 已证明可行，接下来逐步把模型、语言、主题和启动体验迁回正确的源码层。

The forward route

六段清晰航线

每一阶段只解决一组有依赖关系的问题。未通过门禁就缩小范围，不把风险滚入下一阶段；通过后立即释放下一段速度。

Next release

Trust & Truth

先完成所有本地验收，再创建 draft；上传资产不可覆盖，验证成功才公开。移除默认包内未消费的 23MB candidate，关闭默认 experimental subagent，并让伪造环境变量无法跳过完整性校验。

Definition of done

完成，就是每条都能证明

  • 失败的发布永远不会成为公开 latest
  • 同一 tag 无法覆盖已上传资产
  • 直接调用 launcher 不能伪造验证状态
  • 正式 tarball 明显缩小，远程 canary 继续通过
  • 实验扩展默认不注册，显式启用才生效
  • 证据过期或上游漂移时自动 fail closed
  • 热启动 p95 不高于 250ms

North star

让 CoCo 每一次升级，都比上一次更轻、更稳、更自由。

我们保留终端原生、本地优先和 fail-closed 的气质，同时持续吸收上游创新。先让能力住进正确的层，再让 Agent 走得更远。这条路线谨慎，但不保守；有门禁，所以能更快。
